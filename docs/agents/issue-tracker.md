# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues. Use the `gh` CLI and infer the repository from the GitHub `origin` remote.

## Conventions

- Create, read, comment on, label, and close issues with the corresponding `gh issue` commands.
- When a skill says to publish to the issue tracker, create a GitHub issue.
- When a skill says to fetch a ticket, read the issue body, labels, and comments.
- Pull requests are not a request or triage surface.
