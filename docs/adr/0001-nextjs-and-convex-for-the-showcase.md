# Use Next.js and Convex for the showcase

Use Next.js for the application and Convex for its backend because the showcase is intended both to onboard the developer to a similar technology stack and to make reactive product behavior visible to the engineering team. This accepts Convex-specific data and deployment patterns instead of choosing a more conventional database stack; Clerk supplies authentication because its documented Next.js integration is a lower-risk fit for the one-day timebox than the still-experimental Next.js support in Convex Auth.
